# B-side module changelog

[中文](CHANGELOG-B.md)

## 1.6.9

- The settings panel speaks six languages: 简体中文, 繁體中文, English, 日本語, 한국어, Русский, with the wording cleaned up throughout.
- The panel can open the server status page directly, so you can see how this device and the server are doing.
- The remote-control channel now uses a debug process shipped with the module (no need to install adbr yourself), and only that one process is recognised - it no longer mixes with a same-named debug program on the phone.
- The "allow remote control" and "allow adbr remote control" switches stay where they were and behave as before: with the first one off this device no longer talks to the server, and adbr stays off until you tick it.
